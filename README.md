# Berik POS — Windows офлайн касса

pos.berik.c кассасын интернетсіз жұмыс істейтін Windows программасы етіп орайды.
Windows 7 SP1, 8, 10, 11 (64-бит).

## Қалай жұмыс істейді
- `BerikPOS.exe` (C#, .NET Framework 4.8) ішінде жасырын MariaDB (жергілікті база) мен PHP қосылады,
  касса WebView2 терезесінде ашылады. Касса коды — `berik_pos` репосының өзі (жинағанда алынады).
- Бірінші кіру: сервер адресі + компания коды (company.code, мысалы n135). Меню, қызметкерлер, баптаулар серверден тартылады.
- Заказдар, тарих, сменалар жергілікті базаға жазылады және серверге жүктеледі:
  «Серверге жүктеу» батырмасымен немесе интернет бар болса минут сайын (байланыс сапасы тексеріледі).
- v1.0.14: программа бұрынғыдай әрқашан жергілікті кассамен жұмыс істейді (онлайн/офлайн ауысу жоқ),
  бірақ кассаның барлық функциясы бар (жеткізу қосулы). Интернет бар кезде минут сайын серверге жүктейді және
  серверден заказдарды (бүгінгі, QR/сайт заказдары, курьер статустары және бүкіл бұрынғы тарихы) кассаға тартады.
- Кассаға көшірілетіні: меню, заказдар (соңғы 2 күн + ашықтары, `api/sync/state.php` минут сайын), сменалар,
  қызметкерлер, баптаулар. Көшірілмейді: клиенттер базасы, олардың деректері, кэшбэк.
- Чек Windows-тағы әдепкі принтерге диалогсыз шығады (`--kiosk-printing`).
- Деректер: `C:\ProgramData\BerikPOS` (база, логтар, баптаулар). Программа: `C:\BerikPOS`.

## Серверге керек
- `berik_pos` ішінде `api/sync/` (login, pull, push, ping, state). Онлайн режим үшін state.php міндетті.
- SQL: `server/berik_offline_server.sql` (company_device, offline_uuid бағандары).

## Жинау және шығару
- `VERSION` файлындағы нөмірді өзгертіп main-ға push жасаса (немесе `v1.0.0` тегін push етсе), GitHub Actions `BerikPOS-Setup-x.y.z.exe` жасап, Release-ке шығарады.
  Орнатылған программалар жаңа нұсқаны өздері тауып, жаңартады.
- Сервер адресін алдын ала қою: репо Settings → Variables → `BERIK_SERVER` (мысалы `https://pos.example.kz`).

## Құрылым
- `src/BerikPOS` — Windows программасы
- `www/local` — кассадағы синхрон агенті (PHP)
- `build/prepare.ps1` — PHP 8.2, MariaDB 10.4, касса сайтын жинау
- `installer/BerikPOS.iss` — Inno Setup орнатқышы
